# ketch

Tiny portable click-through clock for Windows, based on the Pokétch clock from Pokémon Diamond/Pearl/Platinum.


## Notes
- The app tries to store settings next to the EXE, and falls back to `%LOCALAPPDATA%\ketch\ketch.settings.json` if needed.
